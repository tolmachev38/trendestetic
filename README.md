# Trend Esthetic — сайт оборудования для салонов красоты (Иркутск)

Готовый статический сайт для **GitHub Pages** с **админкой**: меняете тексты, цены, фото, товары, цвета, SEO — нажимаете «Опубликовать», и админка сама коммитит изменения в репозиторий. Через 1–2 минуты сайт обновляется.

---

## Что внутри

```
index.html                  главная (генерируется из content.json)
apparaty/<адрес>/index.html 25 SEO-страниц товаров
katalog/<адрес>/index.html  5 SEO-страниц категорий
404.html                    страница «не найдено»
content.json                ВСЕ данные сайта — их редактирует админка
admin/                      админка (откройте https://ваш-сайт/admin/)
assets/css, js, fonts, img, music, icons
sitemap.xml, robots.txt     для поисковиков
llms.txt, llms-full.txt     для ИИ-ассистентов (нейропоиск)
manifest.webmanifest        иконки и PWA
tools/build.mjs             пересборка страниц без админки (нужен Node.js)
.nojekyll                   отключает обработку Jekyll на GitHub Pages
```

Не редактируйте вручную `index.html`, страницы товаров/категорий, `sitemap.xml`, `robots.txt`, `llms*.txt`, `assets/js/data.js` — они перезаписываются при каждой публикации из `content.json`.

## Шаг 1. Создайте репозиторий

1. Зарегистрируйтесь / войдите на <https://github.com>.
2. Справа вверху **+ → New repository**.
3. Имя репозитория:
   - **лучший вариант для SEO** — `ВАШЛОГИН.github.io` (сайт откроется в корне домена `https://ВАШЛОГИН.github.io/`);
   - или любое имя, например `trend-esthetic` (сайт будет по адресу `https://ВАШЛОГИН.github.io/trend-esthetic/`);
   - идеально — потом подключить **свой домен** (см. шаг 4).
4. Видимость: **Public** (бесплатный GitHub Pages работает с публичными репозиториями).
5. Ничего не добавляйте (README, .gitignore) — нажмите **Create repository**.

## Шаг 2. Загрузите файлы

Всё содержимое папки «ИТОГ САЙТ» должно оказаться **в корне** репозитория (рядом с `index.html` должны лежать `content.json`, `admin`, `assets` …).

### Вариант А — Git в терминале (быстро, у вас Git уже установлен)

Откройте PowerShell в папке «ИТОГ САЙТ» (в Проводнике: правый клик по пустому месту → «Открыть в терминале») и выполните по очереди:

```bash
git init -b main
git add .
git commit -m "Сайт Trend Esthetic"
git remote add origin https://github.com/ВАШЛОГИН/ИМЯ-РЕПОЗИТОРИЯ.git
git push -u origin main
```

При первом `git push` откроется окно входа в GitHub — войдите в браузере.

### Вариант Б — GitHub Desktop (без командной строки)

1. Установите <https://desktop.github.com>, войдите.
2. **File → Add local repository** → выберите папку «ИТОГ САЙТ» → «create a repository» → **Create repository**.
3. **Publish repository** → снимите галочку «Keep this code private» → **Publish**.

### Вариант В — через сайт GitHub

На странице репозитория: **uploading an existing file** → перетащите файлы. GitHub принимает до 100 файлов за раз, поэтому грузите частями: сначала всё, кроме папки `assets`; затем содержимое `assets` по подпапкам (`assets/img` можно в два захода). Следите, чтобы структура папок сохранилась.

## Шаг 3. Включите GitHub Pages

1. В репозитории: **Settings → Pages**.
2. **Source: Deploy from a branch** → Branch: **main**, папка **/(root)** → **Save**.
3. Через 1–2 минуты вверху появится адрес сайта: `https://ВАШЛОГИН.github.io/…/`.

## Шаг 4 (рекомендуется). Свой домен

Для продвижения в Яндексе свой домен (например, `trend-esthetic.ru`) намного лучше поддомена github.io.

1. Купите домен у любого регистратора (REG.RU, Timeweb, Beget, RU-CENTER).
2. В DNS домена создайте записи:
   - `A` → `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153` (для корня домена);
   - `CNAME` для `www` → `ВАШЛОГИН.github.io`.
3. В админке → «Сайт» → **Свой домен** впишите `trend-esthetic.ru`, а в **Адрес сайта** — `https://trend-esthetic.ru/` → Опубликовать (появится файл `CNAME`).
4. GitHub → Settings → Pages → Custom domain → проверьте домен → включите **Enforce HTTPS** (после выпуска сертификата, до суток).

## Шаг 5. Создайте токен для админки

1. GitHub → аватар справа вверху → **Settings** → внизу слева **Developer settings** → **Personal access tokens** → **Fine-grained tokens** → **Generate new token**.
2. Token name: `admin trend-esthetic`; Expiration: например, 1 год (по истечении создайте новый).
3. **Repository access → Only select repositories** → выберите ваш репозиторий.
4. **Permissions → Repository permissions → Contents → Read and write** (Metadata выставится сам).
5. **Generate token** → скопируйте токен `github_pat_…` (он показывается один раз).

Токен = ключ от репозитория. Не пересылайте его, храните только в админке своего браузера. Если токен утёк — удалите его там же, в Fine-grained tokens.

## Шаг 6. Настройте админку и опубликуйте

1. Откройте `https://ваш-сайт/admin/`.
2. **⚙ Подключение** → логин, репозиторий, ветка `main`, токен → **Проверить** (должно быть «✅ Доступ есть») → **Сохранить и загрузить**.
3. Раздел **Сайт** → **Адрес сайта**: впишите настоящий адрес (с `/` на конце). Это важно: от него строятся canonical, sitemap.xml, robots.txt и разметка Schema.org.
4. Раздел **Аналитика** → номер счётчика Яндекс Метрики и коды Вебмастеров (см. ниже).
5. **🚀 Опубликовать** → через 1–2 минуты изменения на сайте (обновите страницу с Ctrl+F5).

Как пользоваться: слева разделы сайта, в центре поля, справа «👁 Предпросмотр». Черновик сохраняется в браузере автоматически (вместе с ещё не опубликованными фото). Товары: добавить, скопировать, скрыть, удалить, поменять порядок; у каждого своя SEO-страница. Порядок и видимость блоков главной меняются в разделе «Порядок блоков».

### Возможности админки

| Что | Где | Как работает |
|---|---|---|
| **✎ Редактор фото** | кнопка у любого фото, в галереях и «Медиатеке»; при загрузке открывается сам | Обрезка с пропорциями (свободно, исходное, 1:1, 4:5, 3:4, 2:3, 16:9, 3:2, 9:16, 1.91:1), поворот на 90°, наклон ±45°, отражение. 16 фильтров («Студия», «Ясный», «Латунь», «Изумруд», «Кино», «Винтаж», «Ч/Б», «Нуар»…) с регулировкой силы. Ползунки: яркость, контраст, насыщенность, тепло, оттенок, света, тени, выцветание, виньетка, зерно, резкость. «◐ До / после» — сравнение. Сохраняет **новый файл** (WebP или JPEG, 1200/1800/2400 px или исходный размер); исходник остаётся. Галочка «Заменить везде» подставит новое фото во все места сайта. |
| **⌖ Кадр на сайте** | там же | Фото больше не обрезается «как получится»: «Заполнить рамку» с точкой фокуса (что всегда остаётся в кадре), «Целиком, без обрезки» (с заливкой полей цветом) или «Как вырезанный аппарат». Сразу видно, как фото ляжет в карточку, широкую и вертикальную рамку. Файл не меняется. |
| **Акции** | Товары → «Старая цена», «Акция действует до» | Старая цена зачёркивается, ставится значок «−N%», в каталоге появляется фильтр «Акции». После даты окончания старая цена и скидка скрываются сами. В разметке для поисковиков — `priceValidUntil`. |
| **Плашки** | Товары → «Плашки на фото» | Готовые: Акция, Скидка, Хит продаж, Новинка, В нашей студии, Премиум, Ростест, Последний в наличии, Под заказ. Любой текст и **любой цвет** («Свой цвет»). |
| **Подписи и кнопки** | раздел «Подписи и кнопки» | ~100 мелких текстов сайта: кнопки, поля формы и сообщения, калькулятор, квиз, контакты, хлебные крошки, страница 404, подсказка музыки. Пустое поле — текст по умолчанию. |
| **Поиск** | строка вверху слева | Находит любой текст на сайте, открывает раздел и ставит курсор в нужное поле. |
| **↶ / ↷** | вверху | Отменить / вернуть изменения (до 100 шагов). Ctrl+Z / Ctrl+Shift+Z — вне полей ввода, Ctrl+S — опубликовать. |

> **Если сайт уже на GitHub и вы правили его через админку:** при обновлении файлов из папки «ИТОГ САЙТ» **не заменяйте `content.json`** — в нём ваши правки. Замените остальные файлы (`admin/`, `assets/js/`, `assets/css/` и т. д.), затем откройте админку и нажмите «🚀 Опубликовать» — страницы пересоберутся с новыми возможностями.

## SEO: что уже сделано

- **Отдельная страница на каждый аппарат** (`/apparaty/…/`) и **на каждую категорию** (`/katalog/…/`) с уникальными title/description под запросы «купить … в Иркутске», хлебными крошками, похожими товарами и формой заявки.
- **Разметка Schema.org (JSON-LD):** Store/LocalBusiness (адрес, координаты, часы, телефоны, города Иркутской области в `areaServed`, ИНН, основатель), WebSite, ItemList, FAQPage, Product + Offer (цена в ₽), BreadcrumbList, CollectionPage.
- **Региональность:** H1 и заголовки с «Иркутск / Иркутская область», блок «География» с городами области, гео-мета-теги, раздел «О компании» с SEO-текстом и блоком фактов.
- **Технически:** canonical, Open Graph + картинка 1200×630, sitemap.xml с картинками, robots.txt (с Clean-param для Яндекса), manifest и иконки, 404, быстрые WebP-изображения с lazy-load, предзагрузка шрифтов и главного фото, семантическая разметка.
- **Нейрооптимизация (GEO):** `llms.txt` и `llms-full.txt` — краткая и полная выжимка о компании, каталоге, ценах и ответах на вопросы для ChatGPT, Алисы/YandexGPT, Perplexity и др.; в robots.txt ИИ-боты явно разрешены; FAQ и «Коротко о компании» сформулированы фактами — так ассистенты охотнее цитируют сайт.

## SEO: что сделать вам (это даёт основной рост)

1. **Яндекс Вебмастер** — <https://webmaster.yandex.ru>: добавьте сайт → подтверждение «Мета-тег» → скопируйте значение `content` в админку (Аналитика → Яндекс Вебмастер) → Опубликовать → «Проверить». Затем: **Индексирование → Файлы Sitemap** → добавьте `https://ваш-сайт/sitemap.xml`; **Региональность** → укажите **Иркутск**; **Переобход страниц** → главная и категории.
2. **Яндекс Бизнес** (карточка в Картах и поиске) — <https://yandex.ru/sprav>: создайте/обновите карточку «Оборудование для салонов красоты», адрес как на сайте, ссылка на сайт, фото аппаратов, цены. Для локального поиска это самый сильный фактор.
3. **2ГИС**: в карточке студии/компании добавьте сайт и раздел с оборудованием.
4. **Google Search Console** — <https://search.google.com/search-console>: подтверждение мета-тегом (поле в админке), отправьте sitemap. **Google Бизнес-профиль** — по возможности.
5. **Яндекс Метрика** — <https://metrika.yandex.ru>: создайте счётчик, номер — в админку. Цель «lead» (отправка заявки) срабатывает автоматически: создайте в Метрике JavaScript-цель с идентификатором `lead`.
6. **Ссылки на сайт**: поставьте ссылку с beauty38.ru («Оборудование для салонов — Trend Esthetic»), из Telegram-канала, Instagram*, VK, Avito (объявления об оборудовании со ссылкой), региональных каталогов Иркутска.
7. **Отзывы** покупателей оборудования в Яндекс Картах и 2ГИС — просите каждого клиента.
8. **Контент**: обновляйте цены и наличие, добавляйте новые аппараты и фото «у нас в студии» — свежесть и уникальные фото помогают.
9. Если сайт на `ВАШЛОГИН.github.io/имя-репозитория/` — поисковики не видят `robots.txt` (он должен лежать в корне домена). Sitemap в этом случае отправьте вручную в Вебмастере. Свой домен (шаг 4) снимает проблему.

Проверка через 2–4 недели после индексации: запросы «купить диодный лазер Иркутск», «аппарат для лазерной эпиляции Иркутск», «оборудование для салона красоты Иркутск», «аппарат для коррекции фигуры купить Иркутск», «оборудование по социальному контракту Иркутск».

## Музыка

- Файл лежит в `assets/music/`, настраивается в админке → «Музыка» (вкл/выкл, автозапуск, громкость, замена файла).
- Браузеры (Chrome, Safari, Firefox) **запрещают звук без действия посетителя**. Поэтому музыка начинает играть с первого клика/касания/нажатия клавиши, а кнопка до этого подсвечивается подсказкой. Если посетитель выключил звук, сайт это запоминает.
- ⚠️ **Авторские права.** Сейчас стоит коммерческий трек известного исполнителя. Публичное использование без лицензии может привести к жалобе правообладателя (DMCA) и блокировке репозитория/сайта на GitHub. Рекомендуем заменить на музыку с лицензией (royalty-free стоки) — в админке «Музыка» → «Загрузить mp3».

## Заявки с сайта

Сейчас форма копирует текст заявки и открывает Telegram (`kosmetolog38Tolmacheva`). Чтобы заявки приходили автоматически, укажите в админке → «Заявка» → **Вебхук** адрес, принимающий POST JSON (например, сценарий Make/Zapier/Albato, отправляющий сообщение в ваш Telegram-бот или CRM).

## Правка без админки

Измените `content.json` и выполните в корне репозитория (нужен Node.js 18+):

```bash
node tools/build.mjs --touch
```

Затем закоммитьте изменения.

## Если что-то пошло не так

- **Админка пишет 401** — токен истёк или скопирован не полностью: создайте новый.
- **403/404** — неверный логин/репозиторий или у токена нет права Contents: Read and write на этот репозиторий.
- **Сайт не обновился** — подождите 2 минуты, проверьте вкладку **Actions** в репозитории (должен пройти «pages build and deployment»), обновите страницу с Ctrl+F5.
- **Откат** — GitHub → вкладка **Commits** → нужный коммит → «Revert», либо в админке «Экспорт / импорт».

*Instagram принадлежит компании Meta, признанной экстремистской и запрещённой в РФ.
