Подключение к GitHub

Админка сохраняет изменения прямо в ваш репозиторий через GitHub API. Токен хранится только в этом браузере и никуда, кроме api.github.com, не отправляется.

Как получить токен: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token → Repository access: Only select repositories (ваш репозиторий) → Permissions → Repository permissions → Contents: Read and write → Generate. Подробно — в README.md.
